# Quickstart: Voice Calls

Give your AI agent a real phone number and make its first voice call.

## Prerequisites

- An Anima API key from [console.useanima.sh](https://console.useanima.sh)
- Python 3.10+ or Node.js 18+
- A phone-enabled agent (or we'll create one below)

## Python

```bash
pip install anima-labs
```

```python
from anima import Anima

anima = Anima(api_key="ak_...")

# Create an agent with a phone number
agent = anima.agents.create(name="Voice Agent")

# Provision a phone number
phone = anima.phones.provision(
    agent_id=agent["id"],
    country_code="US",
    capabilities=["voice", "sms"],
)
print(f"Phone: {phone['phoneNumber']}")

# List available voices
voices = anima.voices.list()
print(f"Available voices: {len(voices['items'])}")

# Make an outbound call
call = anima.calls.create(
    agent_id=agent["id"],
    to="+14155551234",
    voice_id=voices["items"][0]["id"],
    system_prompt="You are a friendly assistant calling to confirm an appointment.",
    greeting="Hi! I'm calling from Dr. Smith's office to confirm your appointment tomorrow at 2 PM.",
)
print(f"Call started: {call['id']}, status: {call['status']}")
```

## Node.js / TypeScript

```bash
npm install @anima-labs/sdk
```

```ts
import { Anima } from "@anima-labs/sdk";

const anima = new Anima({ apiKey: "ak_..." });

// Create an agent with a phone number
const agent = await anima.agents.create({ name: "Voice Agent" });

// Provision a phone number
const phone = await anima.phones.provision({
  agentId: agent.id,
  countryCode: "US",
  capabilities: ["voice", "sms"],
});
console.log(`Phone: ${phone.phoneNumber}`);

// List available voices
const voices = await anima.voices.list();
console.log(`Available voices: ${voices.items.length}`);

// Make an outbound call
const call = await anima.calls.create({
  agentId: agent.id,
  to: "+14155551234",
  voiceId: voices.items[0].id,
  systemPrompt: "You are a friendly assistant calling to confirm an appointment.",
  greeting: "Hi! I'm calling from Dr. Smith's office to confirm your appointment tomorrow at 2 PM.",
});
console.log(`Call started: ${call.id}, status: ${call.status}`);
```

```bash
export ANIMA_API_URL="https://api.useanima.sh"  # optional, defaults to production
export ANIMA_LOG="debug"  # optional, enables debug logging
```



## Handle Inbound Calls

To handle incoming calls, set up a webhook endpoint:

```python
from anima import Anima, fastapi_webhook_dependency
from fastapi import FastAPI, Depends

app = FastAPI()
webhook_dep = fastapi_webhook_dependency("whsec_...")

@app.post("/webhooks")
async def handle(event=Depends(webhook_dep)):
    if event.type == "call.incoming":
        print(f"Incoming call from {event.data['from']}")
    elif event.type == "call.ended":
        print(f"Call ended: {event.data['callId']}")
```

```ts
import express from "express";
import { Anima, webhookMiddleware } from "@anima-labs/sdk";

const app = express();
app.use(express.json());

app.post("/webhooks", webhookMiddleware("whsec_..."), (req, res) => {
  const event = req.webhookEvent;
  if (event.type === "call.incoming") {
    console.log(`Incoming call from ${event.data.from}`);
  } else if (event.type === "call.ended") {
    console.log(`Call ended: ${event.data.callId}`);
  }
  res.sendStatus(200);
});
```

## Real-Time Call Events (WebSocket)

Monitor calls in real-time using WebSocket events:

```ts
const anima = new Anima({ apiKey: "ak_..." });
const stream = anima.events.connect();

stream.on("event", (event) => {
  switch (event.type) {
    case "call.started":
      console.log("Call started:", event.data.callId);
      break;
    case "call.transcription":
      console.log(`[${event.data.speaker}]: ${event.data.text}`);
      break;
    case "call.ended":
      console.log("Call ended, duration:", event.data.durationSeconds);
      break;
  }
});

stream.on("error", (err) => console.error("Stream error:", err));
```
