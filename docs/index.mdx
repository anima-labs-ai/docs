# Anima Docs

Anima gives AI agents a real identity: email inboxes, phone numbers, SMS, voice calls, encrypted vault credentials, addresses, DID-based identity, and 53 MCP tools for agent runtimes.

## Start here

| Path | Use it for |
|------|------------|
| [Quickstart: Email](/docs/quickstart-email) | Send the first message from an agent inbox |
| [Phone & Voice](/docs/phone) | Provision a number, text yourself, and place the first call |
| [Quickstart: Vault](/docs/quickstart-vault) | Store credentials without exposing raw secrets to the model |
| [MCP Servers](/docs/mcp) | Connect Anima to Claude Desktop, Cursor, VS Code, and other MCP clients |

## Core surfaces

- **Email** - agent-owned inboxes, outbound mail, inbound messages, custom domains
- **Phone** - dedicated numbers, SMS, inbound replies, voice-capable provisioning
- **Voice** - outbound calls, transcripts, summaries, call scoring, server-side voice guardrails
- **Vault** - encrypted credential storage, TOTP, ephemeral handles, policy controls
- **Identity** - DIDs, agent cards, registry, addresses, and audit trails
- **MCP** - 53 tools across focused domain servers

## Fast demo

The shortest real-world demo is:

1. Create or select an agent.
2. Provision a phone number with SMS and voice.
3. Send yourself an SMS from the agent.
4. Place a voice call to your phone.
5. Fetch the transcript after the call ends.

Start with [Phone & Voice](/docs/phone) or run the focused [Voice Calls quickstart](/docs/quickstart-voice).
