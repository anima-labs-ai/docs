## List Voices

Retrieve all available voices programmatically, with optional filtering by provider, language, or gender.

```python
from anima import Anima

anima = Anima(api_key="ak_...")

# List all voices
voices = anima.voices.list()
for voice in voices["items"]:
    print(f"{voice['id']}: {voice['name']} ({voice['provider']}, {voice['gender']})")

# Filter by provider
eleven_voices = anima.voices.list(provider="eleven_labs")

# Filter by language
spanish_voices = anima.voices.list(language="es")

# Filter by gender
male_voices = anima.voices.list(gender="male")
```

```ts
import { Anima } from "@anima-labs/sdk";

const anima = new Anima({ apiKey: "ak_..." });

// List all voices
const voices = await anima.voices.list();
for (const voice of voices.items) {
  console.log(`${voice.id}: ${voice.name} (${voice.provider}, ${voice.gender})`);
}

// Filter by provider
const elevenVoices = await anima.voices.list({ provider: "eleven_labs" });

// Filter by language
const spanishVoices = await anima.voices.list({ language: "es" });

// Filter by gender
const maleVoices = await anima.voices.list({ gender: "male" });
```

## Select a Voice for a Call

Specify a `voice_id` when creating a call to use a particular voice.

```python
call = anima.calls.create(
    agent_id="ag_abc123",
    to="+14155551234",
    voice_id="voice_aria",
    system_prompt="You are a friendly customer support agent.",
    greeting="Hi there! Thanks for calling. How can I help you today?",
)
```

```ts
const call = await anima.calls.create({
  agentId: "ag_abc123",
  to: "+14155551234",
  voiceId: "voice_aria",
  systemPrompt: "You are a friendly customer support agent.",
  greeting: "Hi there! Thanks for calling. How can I help you today?",
});
```

## Get Voice Details

Retrieve metadata for a specific voice, including supported languages and a sample audio URL.

```python
voice = anima.voices.get("voice_aria")
print(f"Name: {voice['name']}")
print(f"Provider: {voice['provider']}")
print(f"Sample: {voice['sampleUrl']}")
print(f"Languages: {', '.join(voice['languages'])}")
```

```ts
const voice = await anima.voices.get("voice_aria");
console.log(`Name: ${voice.name}`);
console.log(`Provider: ${voice.provider}`);
console.log(`Sample: ${voice.sampleUrl}`);
console.log(`Languages: ${voice.languages.join(", ")}`);
```

## Voice Settings

Fine-tune voice behavior per call with optional settings:

```python
call = anima.calls.create(
    agent_id="ag_abc123",
    to="+14155551234",
    voice_id="voice_marcus",
    voice_settings={
        "stability": 0.7,        # 0.0-1.0, higher = more consistent
        "similarity_boost": 0.8,  # 0.0-1.0, higher = closer to original
        "speed": 1.0,             # 0.5-2.0, playback speed
        "pitch": 0,               # -12 to 12 semitones
    },
    system_prompt="You are a confident sales representative.",
)
```

```ts
const call = await anima.calls.create({
  agentId: "ag_abc123",
  to: "+14155551234",
  voiceId: "voice_marcus",
  voiceSettings: {
    stability: 0.7,
    similarityBoost: 0.8,
    speed: 1.0,
    pitch: 0,
  },
  systemPrompt: "You are a confident sales representative.",
});
```
