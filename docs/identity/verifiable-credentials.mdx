# Verifiable Credentials

Anima's identity layer is built around W3C Verifiable Credentials (VCs): signed, revocable attestations about an agent (for example "this agent's email is verified" or "this org passed billing verification").

<Note>
  **Current status — read this first.** Credential *verification*, *listing*, and *revocation* endpoints are live. Credential **issuance is not yet exposed**: Anima does not currently issue credentials automatically (or via API), so a fresh agent's credential list is empty and its [Agent Card](/identity/agent-cards) reads `verification.level: "basic"`. Automatic issuance on real events (email verified, phone provisioned, org billing-verified) is on the roadmap; nothing below pretends it shipped.
</Note>

## What works today

### List an agent's credentials

```
GET https://api.useanima.sh/v1/agents/{agentId}/credentials
```

Returns the agent's non-revoked credentials. Until issuance ships this returns `[]` for agents that have not been issued credentials by other means.

### Verify a credential

```
POST https://api.useanima.sh/v1/identity/verify
```

```json
{ "jwtVc": "<compact JWT Verifiable Credential>" }
```

Verifies a JWT-encoded VC: signature against the issuer's DID, expiry, and revocation status. Works for externally issued credentials too — the issuer's DID document just has to be resolvable.

### Revoke a credential

```
POST https://api.useanima.sh/v1/agents/{agentId}/credentials/{vcId}/revoke
```

Master key required. Revoked credentials disappear from the agent's list and fail verification.

## Revocation status

Credentials declare a `StatusList2021` entry in their `credentialStatus` field. A public status-list endpoint (a served bitstring that verifiers can poll) is **not yet available** — revocation is enforced by Anima's own verify endpoint, not by third-party status-list lookup. If you verify Anima-issued credentials outside Anima, call `POST /v1/identity/verify` rather than assuming the status list resolves.

## API Reference

| Endpoint | Method | Description |
| --- | --- | --- |
| `/v1/agents/{agentId}/credentials` | GET | List an agent's credentials |
| `/v1/identity/verify` | POST | Verify a JWT VC (signature, expiry, revocation) |
| `/v1/agents/{agentId}/credentials/{vcId}/revoke` | POST | Revoke a credential (master key) |
